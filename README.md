# Retro Snake and Ladders with DE1-SoC

A retro Snake and Ladders game controlled from the pushbuttons on a DE1-SoC board. The game window, board logic, animation, audio, PvP mode, and AI mode run in Python with Pygame, while a small ARM C program runs from the Intel FPGA Monitor Program and bridges the DE1-SoC hardware to the Python game over UART.

## Project Layout

| File | Purpose |
| --- | --- |
| `game.py` | Main Python/Pygame game. Draws the board, handles rules, plays sounds, reads UART commands, and sends score packets back to the board. |
| `getting_started.c` | ARM-side DE1-SoC program. Reads pushbuttons, sends commands over UART, receives game packets, and updates the 7-segment HEX displays. |
| `address_map_arm.h` | DE1-SoC memory map definitions used by the Monitor Program project. |
| `makefile` | Intel FPGA Monitor Program generated build file for the ARM program. |
| `dice.wav`, `bell.wav`, `snake.wav`, `win.wav` | Game sound effects. |
| `something.amp` | Intel FPGA Monitor Program project/configuration file. |

Generated Monitor Program build outputs such as `.axf`, `.srec`, `.o`, and `.objdump` are ignored by Git.

## How It Works

The project is split into two parts:

1. **DE1-SoC ARM program (`getting_started.c`)**
   - Polls the board pushbuttons from `KEY_BASE`.
   - Sends single-character UART commands to the PC:
     - `KEY0` sends `1` to roll the dice.
     - `KEY3` sends `2` to restart the game.
     - `KEY1` sends `3` to select PvP mode.
     - `KEY2` sends `4` to select AI mode.
   - Receives game-state packets from Python using this format:

     ```text
     [0xFF, roll, player_number, position_tens, position_units]
     ```

   - Updates the HEX displays:
     - `HEX2` shows the latest dice roll.
     - `HEX1` and `HEX0` show Player 1 position.
     - `HEX5` and `HEX4` show Player 2 position.

2. **Python game (`game.py`)**
   - Opens a serial connection to the DE1-SoC.
   - Draws a 10x10 Snake and Ladders board with Pygame.
   - Supports PvP and AI modes.
   - Handles snakes, ladders, bouncing back when a roll passes 100, win detection, and audio feedback.
   - Sends updated dice/player/position packets back to the DE1-SoC so the HEX displays stay synchronized.

## Requirements

### Hardware

- Terasic DE1-SoC board
- USB connection between the PC and DE1-SoC
- Intel FPGA Monitor Program setup for the DE1-SoC ARM processor

### Software

- Python 3
- Intel FPGA Monitor Program
- Python packages listed in `requirements.txt`

Install the Python dependencies:

```powershell
pip install -r requirements.txt
```

## Serial Port Setup

`game.py` currently expects the DE1-SoC UART on:

```python
DE1_PORT_NAME = 'COM5'
BAUD = 115200
```

If your board appears on a different COM port, edit `DE1_PORT_NAME` in `game.py` before running the game.

If the Python script cannot open the DE1-SoC serial port, it falls back to keyboard mode for testing.

## Running the Game

1. Open the project in Intel FPGA Monitor Program.
2. Build and run `getting_started.c` on the DE1-SoC ARM processor.
3. In a terminal from this folder, install dependencies if needed:

   ```powershell
   pip install -r requirements.txt
   ```

4. Start the Python game:

   ```powershell
   python game.py
   ```

5. Use the DE1-SoC pushbuttons:
   - `KEY1`: choose PvP mode
   - `KEY2`: choose AI mode
   - `KEY0`: roll dice
   - `KEY3`: restart

Keyboard fallback:

- `Space`: roll dice
- `R`: restart

## Game Rules

- The board has 100 cells.
- Players start from position 0 and move according to a random dice roll from 1 to 6.
- If a player rolls past 100, they bounce backward from 100.
- Landing on a ladder moves the player upward.
- Landing on a snake moves the player downward.
- The first player to reach exactly position 100 wins.

## Notes

- Keep the WAV files in the same directory as `game.py`; the game loads them with relative paths.
- The included `makefile` was generated by the Intel FPGA Monitor Program and contains toolchain paths specific to that environment.
